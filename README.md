# SHAR Production Evidence Records

Twenty-five bilingual machine-readable contracts for production evidence, published by **[SHAR Production](https://sharprod.com/)**.

Each contract has an EN and RU interactive page, JSON Schema, a clearly synthetic valid example and a small browser validator. The collection covers approvals, rights, permits, technical reports, quality control, localization, delivery, archive, provenance, supplier review, incidents and final release gates.

```sh
npm run check
```

Code, schemas and documentation use MIT. Synthetic fixtures use CC-BY-4.0. The project contains no client data, media, credentials, analytics or performance claims.
